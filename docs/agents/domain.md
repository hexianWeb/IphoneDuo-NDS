# Domain Docs

本仓库采用单上下文布局。

## 探索前读取

- 根目录 `GLOSSARY.md`：读取项目术语及其定义。
- `docs/adr/`：读取与当前改动领域有关的决策记录。

文件不存在时静默继续，不将缺失视为问题，也不提前创建占位文件。
由 domain-modeling 在术语或决策实际明确后按需创建。

## 消费规则

- Issue、规格、测试名和重构建议使用词汇表中的术语，不擅自换同义词。
- 需要的概念尚未定义时，先判断是否沿用现有概念；确有缺口则交由 domain-modeling 补充。
- 建议与现有 ADR 冲突时，明确指出 ADR 编号和重新讨论的理由，不静默覆盖决定。
- 产品规则与实现状态仍按 AGENTS.md 中的 PRD、项目规则和进度文档入口读取。
